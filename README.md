# ☕ High Bros Café

A modern **restaurant / café website UI** built using **React (Vite) and Tailwind CSS**.

This project focuses on creating a **visually appealing, responsive, and professional café website UI** that can be presented as a demo to café or restaurant owners.

The goal is to showcase **clean UI design, reusable React components, and modern frontend development practices**.

---

## 🚀 Features

- Modern café / restaurant landing page
- Clean and professional UI
- Fully responsive design
- Built using reusable React components
- Styled with Tailwind CSS
- Fast development using Vite

---

## 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- HTML5
- CSS3
